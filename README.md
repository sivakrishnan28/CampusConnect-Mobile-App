# CampusConnect – Mobile App Interactive Prototype

## Project Overview

CampusConnect is a student-focused mobile app UI/UX prototype designed in Figma to provide easy access to academic information.

## Features

* Splash Screen
* Student Login
* Home Dashboard
* Class Timetable
* Assignments
* Assignment Details
* Study Materials
* Student Profile
* Interactive Navigation

## Tools Used

* Figma
* Visual Studio Code
* Git and GitHub
